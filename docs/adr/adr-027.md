# ADR-027 : Clé naturelle et texte exploitable

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

L'ingestion rejoue les mêmes exports ; il faut éviter les doublons de stockage et ignorer les textes trop pauvres.

## Décision

Clé naturelle d'une offre : source, identifiant de la source et date de collecte, avec insertion idempotente ; un texte est exploitable à partir de 200 caractères. Le texte conservé est masqué (courriels, téléphones) à l'ingestion (ADR-011).

## Conséquences

Rejeu sans effet de bord ; l'atomicité sous concurrence reste à vérifier par un test.

## Alternatives

Clé générée seule ; aucun seuil de texte.
