# ADR-008 : Stockage et modèle de données

- **Statut :** Décidé le 8 novembre 2026.

## Décision

PostgreSQL, migrations versionnées avec Flyway, réponses brutes en JSONB dans une table purgeable. Schéma par module ou schéma unique : à départager sur le critère « respect des frontières de module dans la base », ajouté après avoir constaté l'égalité des deux.

## Preuves

Transactions « tout ou rien » et durables [60] ; fonctions de fenêtre pour les agrégats [60] ; migrations versionnées appliquées une seule fois et immuables [61] ; un `DELETE` ne supprime physiquement la ligne qu'après un `VACUUM` [60] ; privilèges par schéma [60].

## Notation préliminaire

PostgreSQL 265 sur 300 (schéma par module ou unique), SQLite 240, PostgreSQL avec fichiers pour les textes 235, MongoDB 170.

## Conséquences

Un serveur de base de données à lancer et à sauvegarder ; la destruction physique des textes demande un `VACUUM`, et les sauvegardes contiennent les textes tant que l'ADR-011 n'a pas statué.

## Alternatives

SQLite (crédible si aucun serveur de base de données n'est disponible) ; MongoDB ; textes dans des fichiers séparés.
