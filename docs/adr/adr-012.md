# ADR-012 : API et contrat

- **Statut :** Proposé, code d'abord choisi par l'équipe.

## Décision proposée

API REST dont le contrat OpenAPI est généré à partir du code, exporté et versionné dans le dépôt ; objets de réponse dédiés ; test d'absence de texte complet dans le contrat ; erreurs au format RFC 9457.

## Preuves

OpenAPI décrit les API HTTP indépendamment du langage [53] ; springdoc génère le contrat depuis le code et sert une interface de consultation [66] ; le code d'abord est plus rapide pour les petites équipes et les conceptions mouvantes, le contrat d'abord facilite le travail en parallèle [67].

## Notation préliminaire

Contrat d'abord 280 sur 300, code d'abord 265, pages côté serveur 255, GraphQL 195 ; l'écart entre les deux premiers est faible.

## Conséquences

Démarrage rapide ; l'interface doit attendre les premiers points d'entrée ; le contrat versionné fait apparaître les changements en revue.

## Alternatives

Contrat d'abord ; GraphQL ; pages rendues côté serveur.
