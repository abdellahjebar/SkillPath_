# ADR-004 : Interface web

- **Statut :** Décidé le 8 novembre 2026. Remplace le choix initial de React, retenu sans critères écrits ; le critère « compétences de l'équipe » est à réévaluer après les réponses de l'équipe.

## Contexte

Le tableau de bord demande des tableaux, filtres, graphiques avec intervalles de confiance et formulaires. L'outil sera repris par l'établissement, et l'interface consomme l'API de l'ADR-012.

## Décision

Angular 22, Apache ECharts pour les graphiques, client TypeScript généré depuis le contrat OpenAPI exporté.

## Preuves

Depuis la version 22, une version majeure par an, support de 24 mois dont 12 de correctifs critiques et de sécurité (jusqu'en juin 2028 pour la version 22) [57] ; protection contre l'injection de scripts intégrée [58] ; générateur de client pour Angular 9 à 22 [59].

## Notation préliminaire

Angular 275 sur 300, pages rendues côté serveur 215, Vue 210, React avec Vite 205 ; l'avance subsiste si le critère « compétences de l'équipe » est supprimé ou égalisé.

## Conséquences

Cadre complet et cycle de support annoncé, favorables à la reprise ; courbe d'apprentissage si l'équipe ne connaît pas Angular ; choix de la bibliothèque de composants laissé aux développeurs de l'interface, documenté dans une fiche de décision.

## Alternatives

React avec Vite ou avec un framework ; Vue ; Thymeleaf et htmx.
