# ADR-023 : Gouvernance du dépôt

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

Équipe de cinq, travail en parallèle, relectures nécessaires.

## Décision

Branches courtes, pull request relue avant fusion, CODEOWNERS par module, titres de commit et de PR en anglais, descriptions en français, aucune clé ni donnée privée dans le dépôt. Les structures proposées sont un point de départ : chacun peut les faire évoluer par une fiche de décision.

## Conséquences

Historique lisible ; responsabilités visibles ; les décisions de structure restent révisables.

## Alternatives

Poussée directe sur main ; relecture facultative.
