# ADR-021 : Module Extraction

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

L'extraction des compétences est le cœur du produit et change de méthode selon les mesures. Elle doit être remplaçable sans toucher à l'ingestion ni à l'analyse.

## Décision

Un module Extraction distinct, derrière une interface « extracteur » (dictionnaire d'abord, racinisation, embeddings, hybride). Il dépend de Référentiel et d'Ingestion. Un conteneur Python d'embeddings est un adaptateur conditionnel (ADR-010).

## Conséquences

Sept modules au lieu de six ; Ingestion ne fait plus d'extraction ; la méthode se change par un adaptateur.

## Alternatives

Extraction dans Ingestion ; service Python dès le départ.
