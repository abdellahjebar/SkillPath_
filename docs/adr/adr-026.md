# ADR-026 : Instantanés et gel

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

Les programmes et les analyses doivent rester comparables dans le temps.

## Décision

Chaque analyse s'appuie sur un instantané daté des données ; une version publiée du référentiel de la formation est figée pendant 45 jours ; les mois s'entendent « avant collecte ».

## Conséquences

Reproductibilité des résultats ; stockage des instantanés à dimensionner.

## Alternatives

Calcul à la volée sur les données courantes.
