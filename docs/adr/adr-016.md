# ADR-016 : Stratégie de tests

- **Statut :** Proposé.

## Décision proposée

Pyramide de tests : tests unitaires des formules avec des valeurs de référence calculées indépendamment, tests d'intégration avec un PostgreSQL réel en conteneur, vérification des modules, tests de conformité (contrat sans texte complet, droits par rôle), tests de l'interface et deux ou trois parcours de bout en bout ; évaluation de l'extraction à la demande.

## Preuves

Beaucoup de tests rapides, peu de tests de bout en bout, qui sont lents et instables [74] ; la base en mémoire H2 n'émule qu'un sous-ensemble des différences entre bases [75] ; tests de module avec simulation des dépendances [51].

## Notation préliminaire

Pyramide avec jeux de référence et conformité 240 sur 300, pyramide avec vraie base 190, avec base H2 170, bout en bout 100, manuel 80.

## Conséquences

Les régressions de conformité sont détectées automatiquement ; effort d'écriture plus élevé ; Docker requis pour les tests d'intégration.

## Alternatives

Tests manuels ; base en mémoire ; bout en bout dominant.
