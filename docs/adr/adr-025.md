# ADR-025 : Déduplication des offres

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

Une même offre est publiée par plusieurs partenaires ; les compter plusieurs fois fausserait D.

## Décision

Doublon exact : même texte, même employeur, même code et même lieu. Doublon proche : similarité de Jaccard sur des groupes de cinq mots, au-dessus de 0,9 ; revue manuelle entre 0,7 et 0,9. Une offre disparue après deux collectes manquées est considérée comme retirée.

## Conséquences

Un seuil à recalibrer sur l'échantillon réel ; une file de revue à prévoir.

## Alternatives

Aucune déduplication ; empreinte exacte seule.
