# ADR-022 : Structure interne et communication entre modules

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

Les modules doivent pouvoir être développés en parallèle par cinq personnes sans casser les frontières.

## Décision

Chaque module expose une interface Java publique (…Api) et des records à la racine de son paquet ; le reste est dans internal/ (web, application, domain, infrastructure) selon le profil du module. Les appels entre modules sont des appels Java directs, pas du HTTP. Chaque module possède ses tables, sans jointure entre modules. Les dépendances autorisées sont déclarées dans package-info.java et vérifiées par ModularityTests.

## Conséquences

Ajouter une dépendance est une décision écrite ; un module simple reste simple ; le noyau commun est ouvert et sans métier.

## Alternatives

Couches globales ; HTTP interne ; entités partagées.
