# ADR-013 : Identité et accès

- **Statut :** Décidé le 8 novembre 2026.

## Décision

Comptes locaux avec Spring Security, mots de passe hachés (Argon2id de préférence, ou BCrypt), longueur minimale conforme à l'OWASP, limitation des tentatives par compte, durée de session limitée, rôles dans la base, droits appliqués par un mécanisme commun sur les contrôleurs, règle « ses propres modules » vérifiée avec l'identité fournie par la sécurité, cookie de session et protection CSRF configurée pour une application monopage (depuis Spring Security 6 : cookie du jeton lisible par Angular et gestionnaire de jeton dédié), avec un test ; table prévue pour un identifiant externe, afin de passer à la connexion unique de l'établissement si elle est disponible ; double authentification hors première version.

## Preuves

Fonctions de hachage adaptatives [68, 69] ; Angular lit le cookie de jeton CSRF et renvoie l'en-tête correspondant [58] ; les jetons restent côté serveur, l'application navigateur seule étant la plus exposée [70].

## Notation préliminaire

SSO de l'université 245 sur 300 (disponibilité inconnue), comptes locaux 240, Keycloak 200, fournisseur externe 195.

## Conséquences

Aucune dépendance externe ; l'établissement hérite d'une gestion de comptes ; double authentification à ajouter.

## Alternatives

Connexion unique de l'établissement ; serveur d'identité auto-hébergé ; fournisseur externe géré.
