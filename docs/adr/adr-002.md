# ADR-002 : Taxonomie des compétences

- **Statut :** Décidé le 8 novembre 2026.

## Décision

ESCO v1.2.1 en français, pour ses URI stables, ses alias et sa couverture multilingue. Réutilisation gratuite « pour tout usage », avec mention obligatoire de l'utilisation d'ESCO [17], complété par une liste locale à deux niveaux (ADR-007) pour les compétences absentes du référentiel.

## Alternatives

Dictionnaire maison ; ROME seul ; ESCO seul.
