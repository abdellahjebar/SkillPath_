# ADR-003 : Style d'architecture

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

Équipe de cinq, soutenance le 20 janvier 2027, charge faible, outil appelé à servir l'établissement. Priorités : exactitude, traçabilité, conformité, reproductibilité et collecte sans doublon.

## Décision

Monolithe modulaire côté serveur à un seul exécutable (Spring Boot 3.5 et Spring Modulith 1.4), sept modules (Ingestion, Référentiel, Programmes, Extraction, Analytique, Accès, Pipeline) plus un noyau commun ouvert, frontières vérifiées par un test de la CI avec les dépendances autorisées déclarées. L'application Angular est un second artefact servi en fichiers statiques.

## Preuves

Ne pas démarrer en microservices [46] ; coût des microservices [47] ; base partagée et couplage des schémas [48] ; transactions entre services [49] ; vérification des modules [51] ; grand monolithe modulaire en production [52].

## Notation préliminaire

Monolithe modulaire 285 sur 300, monolithe en couches 250, deux points d'entrée 235, microservices avec base partagée 120, avec une base par service 65.

## Conséquences

Transactions locales ; un seul processus ; pas de déploiement indépendant par module ; frontières maintenues par des tests ; un composant externe (conteneur Python) reste acceptable s'il n'a pas de base propre, s'il est sans état, versionné et déployé avec le monolithe et appelé par l'interface d'extraction ; sinon la décision est rouverte.

## Alternatives

Monolithe en couches ; monolithe modulaire à deux points d'entrée ; microservices avec base partagée ; microservices avec une base par service.
