# ADR-006 : Ensemble des compétences retenues

- **Statut :** Décidé le 8 novembre 2026.

## Décision

L'ensemble C réunit la collection des compétences numériques d'ESCO, des compétences de gestion choisies, les entrées de la liste locale et toute compétence rattachée à un module. Les compétences transversales sont stockées mais exclues du calcul de l'écart.

## Conséquences

Un tableau de bord lisible, et aucun module invisible ; un indicateur « incluse dans le calcul » par compétence.

## Alternatives

Toutes les compétences d'ESCO ; seulement celles vues dans les offres.
