# ADR-020 : Version du cadre et migration

- **Statut :** Décidé le 8 novembre 2026.

## Contexte

Spring Boot 3.5.16 est la dernière version libre de la branche 3.5, dont le support libre se termine le 30 juin 2026. Spring Boot 4 vient de sortir et est jugé insuffisamment éprouvé.

## Décision

Spring Boot 3.5.16, Spring Modulith 1.4.13, Java 25 (repli : Java 21), Maven avec wrapper. Migration vers Spring Boot 4.1 ou 4.2 avant tout déploiement, tracée par une fiche de décision. Dependabot suit les mises à jour.

## Conséquences

Version éprouvée pendant le développement ; dette de migration assumée et datée ; le support payant de la branche 3.5 reste à vérifier.

## Alternatives

Spring Boot 4 dès le départ ; Spring Boot 3.5 sans plan de migration.
